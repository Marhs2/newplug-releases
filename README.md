# NewPlug 메일

메일플러그(IMAP/SMTP) 계정용 데스크톱 메일 프로그램입니다.

## 내려받기

**[최신 버전 받기 →](https://github.com/Marhs2/newplug-releases/releases/latest)**

| 운영체제 | 파일 |
|---|---|
| Windows (64비트) | `NewPlugMail-<버전>-Windows-Setup.zip` → 압축을 풀고 `NewPlugMail-Setup.exe` 실행 |
| macOS (Apple Silicon) | `NewPlugMail-<버전>-macOS-arm64.dmg` → 열어서 앱 실행 |

## 처음 실행할 때

- 서명이 없는 앱이라 경고가 나올 수 있습니다.
  - Windows: SmartScreen에서 "추가 정보 → 실행"
  - macOS: 앱을 Control-클릭 → 열기
- 메일플러그 웹메일 [환경설정 → IMAP/SMTP]에서 사용을 켜 주세요.
